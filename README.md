______Banking Transaction System______

A simple GUI-based Banking Transaction System built using Python and Tkinter.

##### Features #####

- Teller Login System
- Cash Withdrawals
- Cash Deposits
- Balance Checking
- Minimum Balance Warning
- Multi-window GUI Interface
- Custom Window Icons

---

##### Technologies Used #####

- Python 3
- Tkinter
- ttk Widgets

_____ Features Explained _____

##### Login System #####
Users must enter valid username and password to access the system.

##### Withdrawals #####
- Prevents invalid withdrawals
- Checks insufficient balance
- Warns when balance goes below minimum balance

##### Deposits #####
Users can deposit money into selected accounts.

##### Balance Checking #####
Displays updated account balance instantly.

____ Notes ____

- This project uses in-memory data storage.
- Account details reset when the program restarts.
- This project is created for educational purposes.
